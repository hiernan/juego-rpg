# ItemCatalogService

`scripts/services/ItemCatalogService.gd` centraliza consultas de catalogo para items, armas y armaduras.

Incluye helpers como `get_item_by_id`, `get_weapon`, `get_armor`, `get_item_kind`, `get_item_display_name` y `get_item_tooltip`.

`GameData.gd` conserva las fachadas existentes para mantener compatibilidad con escenas y scripts actuales.
