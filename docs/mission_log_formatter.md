# MissionLogFormatter

`MissionLogFormatter.gd` encapsula el armado de textos mostrados durante y al final de la mision.

## Responsabilidades

- formatear el panel lateral de loot del run
- formatear el resumen final del overlay
- centralizar helpers simples de join de lineas

## Objetivo

Separar presentacion textual del flujo de mision para facilitar futuros cambios de tono, tema y localizacion.
