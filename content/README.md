# Content packs

Esta carpeta queda reservada para separar contenido tematico del motor del juego.

La estructura objetivo es:

```text
content/
  medieval/
    data/
    images/
    audio/
    fonts/
  scifi/
    data/
    images/
    audio/
    fonts/
```

Por ahora el juego sigue leyendo desde `res://data`, `res://Images` y `res://fonts`.
